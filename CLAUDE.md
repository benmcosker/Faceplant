# Faceplant

A think piece disguised as a social network: humans sign in with a magic link
and post; a roster of bot personas swarms every human post with in-character
replies generated by the Anthropic API. The app exists to make manufactured
engagement visible — and to put a price tag on it.

Read this before changing anything. Every delegated context loads this file, so
it is the one place where a fact only has to be written once.

## Layout

```
backend/            FastAPI + SQLAlchemy + APScheduler (port 8001)
  app/routers/      HTTP surface: auth, posts, comments, likes, ads, costs, admin_bots
  app/bots/         The swarm: roster.py (personas), reactions.py (engine),
                    origination.py (bots posting unprompted), house_style.py
  app/models.py     SQLAlchemy tables      app/schemas.py  Pydantic wire types
  app/config.py     pydantic-settings; every knob is an env var with a default
  tests/            pytest, SQLite-backed, no network (conftest.py stubs keys)
frontend/           React 19 + MUI + Vite (port 5174)
  src/api.ts        Typed client — mirrors backend/app/schemas.py
  src/components/   Each component has a colocated *.test.tsx
  cypress/e2e/      Specs stub the backend with cy.intercept(); no API needed
docs/orchestration.md   How to run this repo with an orchestrator + subagents
```

## Commands

```bash
cd backend  && pytest              # backend suite
cd frontend && npm run test        # vitest
cd frontend && npm run lint        # oxlint
cd frontend && npm run build       # tsc -b && vite build — the type check
cd frontend && npm run e2e         # Cypress, boots the dev server itself
```

CI (`.github/workflows/ci.yml`) runs pytest for the backend, and lint + test +
build for the frontend. A change is not done until those pass.

## Rules that bite

- **The wire contract is two files.** `backend/app/schemas.py` and
  `frontend/src/api.ts` describe the same JSON. Change one, change the other in
  the same commit, or the UI breaks in a way no unit test catches.
- **Every model call costs money and gets metered.** `app/usage.py` records
  tokens and dollars; the cost meter in the UI reads them. New Anthropic calls
  must record usage the same way, or the meter quietly lies.
- **Spend has three independent brakes** in `bots/reactions.py`: generation
  depth, a per-thread reaction cap, and `global_spend_ceiling_usd` as a global
  kill-switch. Do not add a code path that reaches the API around them.
- **Expensive behavior ships off by default.** Bot-to-bot loops, the Batch API
  path, prompt caching, and bot origination are all opt-in settings. Keep new
  ones that way.
- **Tests never touch the network or the dev database.** `tests/conftest.py`
  points at a throwaway SQLite file and fake keys; stub the Anthropic and Giphy
  clients rather than calling them.
- **Personas live in the roster, not in the engine.** Voice belongs in
  `bots/roster.py` (`persona`, `voice_notes`) and `bots/house_style.py`. If you
  find yourself special-casing a username inside `reactions.py`, stop.

## Conventions

- Backend errors return `{error, code, status}` via the handler in `main.py`.
- `persona` is stored in the DB; `voice_notes`, `uses_giphy`, and
  `avatar_source` are roster-only and never reach a table.
- Comments in this codebase explain *why* a constraint exists, not what a line
  does. Match that.
- Frontend components are function components with colocated tests. New
  component, new `*.test.tsx`.
